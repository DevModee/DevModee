## About

I'm **Matías**, a developer from **Argentina** focused on shipping production software across full-stack web & Android marketplaces, MCP servers on npm, lightweight Linux tooling, and native Windows desktop software in C# and Rust.

- **Creator of [PelleMarket](https://pellemarket.com):** local marketplace live on web (`v2.2`) and **[Google Play](https://play.google.com/store/apps/details?id=dev.pellemarket.app)**, presented to the Pellegrini Chamber of Commerce.
- **Author of [mercadopago-mcp](https://github.com/DevModee/mercadopago-mcp):** read-only-by-default MCP server for Mercado Pago published on **[npm](https://www.npmjs.com/package/mercadopago-mcp)**, rated **A** on **[Glama](https://glama.ai/mcp/servers/DevModee/mercadopago-mcp)**, and verified on **HOL Guard** (`mcp.mercadopago-mcp`).
- **Founder of [Aeros](https://aerosdev.com):** home to **[Covalos](https://www.covalos.com)** (`v0.8.8` public beta, native Rust IDE for Windows, macOS & Linux), **[Atom](https://aerosdev.com/atom)** (`v2.14.0` public beta), **[Aeros-Panel](https://github.com/DevModee/Aeros-Panel)** (`~27.1 MB` idle RAM on Debian 13), and production Minecraft / Hytale plugins.

## Open-Source & Side Projects

- 🎨 **[egui-dither-bg](https://github.com/DevModee/egui-dither-bg)** Two-pass GPU GLSL Bayer 8x8 ordered-dither interactive background for `egui` / `eframe` (extracted from **Covalos**).
- ⚡ **[presentmon-frametimes](https://github.com/DevModee/presentmon-frametimes)** Zero-dependency .NET 10 library and CLI for capturing and analyzing Intel PresentMon frametimes, 1% / 0.1% lows, P99/P99.9, and stutters (extracted from **Atom**).
- 🔌 **[Hytale-DiscordSync](https://github.com/DevModee/Hytale-DiscordSync)** Two-way real-time chat and status bridge connecting Hytale servers and Discord.
- 🖥️ **[minecraft-server-panel](https://github.com/DevModee/minecraft-server-panel)** Multi-server Minecraft desktop control panel with live console output and Java checks.
- 🧩 **[PulsePrison-Addon-Example](https://github.com/DevModee/PulsePrison-Addon-Example)** Official developer API addon template for PulsePrison Core (Paper / Folia 1.20.4+).
